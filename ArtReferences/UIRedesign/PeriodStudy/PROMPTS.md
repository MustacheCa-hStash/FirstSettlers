## Shared prompt

Use case: ui-mockup. Asset type: isolated full game UI overlay with GENUINE TRANSPARENT ALPHA BACKGROUND, intended for deterministic compositing onto real game screenshots.
Input image: the approved Quiet overlay screenshot, a UI LAYOUT / CONTENT REFERENCE ONLY. Extract/recreate only the interface, entirely discard its scenery. Do not create or include any world, landscape, sky, trees, leaves, water, rocks, flowers, gradients outside panels, vignette, global shadows or background dimming sheet. The spaces between panels, area right of the detail panel, and the outer margin MUST be truly transparent alpha, not a checkerboard painting. Panel interiors must be clean material surfaces with no scenery baked into them. Alpha of panel interiors can be approximately .94; all UI text and item models remain opaque.
Composition must follow the reference spatially on a wide 16:9 transparent canvas: narrow categories panel at x 4.5%-20%, y7.5%-81.5%; main 3-column part grid panel x20.8%-56.3%, same y7.5%-81.5%; selected-piece details panel x57%-81%, same y; bottom favorites shelf x16.5%-81%, y83.5%-94.5%; small footer keyhint strip x81.5%-98%, y89%-94.5%. Maintain all panel gaps genuinely transparent. Interface fills these regions naturally. Retain legible modest type size, dense readable grid, selected right-triangle Half-gable. Avoid playful chunky lettering, crooked brush strokes, cartoon signs or puffy controls. Preserve functional grouping and restrained maturity.
Exact text: BUILD / Ordinary wood kit. Category rail: All pieces, Foundations, Walls, Floors, Posts, Stairs, Roofs. Main grid row order: Stone foundation, Timber floor, Split-plank wall; Bay post, Wattle wall, W21 stair; Thatch roof, Doorway wall, Window wall; Half-gable as selected final row. Selected details: Half-gable / 2 × 2 × 0.25 m / R Flip slope / Q / E Turn 45° / 0.25 m placement grid / Choose piece. Bottom: Building favorites (concept). Footer: Tab Components | B / Esc Exit.
Render thumbnails as matte stylized timber/stone models matching reference, with plain diffuse lighting. Half-gable must be one RIGHT TRIANGLE: vertical left edge, horizontal base, one diagonal descending from upper-left to lower-right. Thatch roof is single pitched panel. Doorway and window wall have clear rectangular apertures. Favorites are individual pieces. No added costs or gameplay tabs. No explanatory annotations or concept titles beyond given text. Entire output transparent except interface and models.
