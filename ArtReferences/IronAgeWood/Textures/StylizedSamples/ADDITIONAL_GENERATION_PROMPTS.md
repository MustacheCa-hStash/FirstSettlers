## Golden oak

```text
Use case: style-transfer.
Asset type: base-color wood trim-sheet artwork, square 2048 by 2048.
Input images: Image 1 is the previously accepted Soft Hewn Oak SOURCE ARTWORK, the edit target and strict atlas layout reference. Image 2 is a First Settlers gameplay screenshot, style reference only.
Primary request: Create a distinct "Golden oak" variant with the light wheat-golden beige and subdued tan oak-plank color associated with Minecraft oak planks. COLOR inspiration only; retain First Settlers' broad hand-painted low-poly surface vocabulary. Material should be substantially LIGHTER and LESS ORANGE than Image 1. Approximate palette: main warm wheat-tan #B89B66, soft pale golden-beige highlights #D2B17A, quiet grain #94794D. Use broad smooth flat painted planes and only a few sparse long gently angular grain grooves, subtle knots. Avoid deep burnt orange, caramel, harsh black cracks, and shiny stylized bevel highlights. It should look like fresh pale oak, not orange varnished wood. Endgrain 5-7 subdued broad rings. Lashing in pale flax, bark a coordinated dull brown. Match the rustic game kit's clean simple wood, no new objects or scenery.
Composition/UV contract: use Image 1's exact nine-region square atlas layout. FOUR full-width horizontal bands fill the TOP HALF, each exactly 1/8 canvas height: A riven timber (y=0..1/8), B alternate riven timber (y=1/8..1/4), C hewn timber (y=1/4..3/8), D bark (y=3/8..1/2). Grain runs horizontally in all four. No board divisions, plank joints, nails, vertical seams, or picture framing. B is critically important: existing wood UVs crop arbitrary areas here, so smooth color and sparse continuous long grain must fill the entire band. C has broad low-contrast axe facets; D has chunky simplified bark shapes.
BOTTOM LEFT QUARTER: two equal 1/4-by-1/4 end-grain squares E and F side by side from y=1/2..3/4; no circular outer silhouette or border, rings fill the square. Fiber lashing G fills x=0..1/2,y=3/4..7/8. Tight grain H fills x=0..1/2,y=7/8..1.
BOTTOM RIGHT QUARTER: I wattle, x=1/2..1,y=1/2..1, preserve Image 1's pattern as reference. This region will be replaced with the exact original RGBA region in final packing to preserve alpha.
Entire canvas is atlas artwork, no labels, text, logos, watermarks, frames or space outside the atlas. Exactly preserve these normalized boundaries. Uniform neutral diffuse albedo; no photographic pores, micro scratches, shiny grain, specular glints, baked directional lighting, cast shadows or vignettes. Wood opaque. Make A-D seamless across their left/right edges. No pixel-art treatment; only the COLOR direction is inspired by Minecraft, the surface style must match First Settlers.
```
